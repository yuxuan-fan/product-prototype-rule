# 产品原型规范（product-prototype-rule）

一套用于生成「可交互前端原型网页」的个人规范，供 AI 助手在用户明确要求按本规范生成/迭代原型页面时加载执行。

## 仓库结构

- `SKILL.md` — 规范正文：核心原则、工作流程、布局基准（B 端/C 端）、适用状态、组件规范、交互流转、验收清单、标注层交付说明。
- `references/design-tokens.md` — 默认设计 token（基于 Arco Design 风格）：颜色、字号、间距、圆角阴影、现代视觉规范。用户提供了参考图时以参考图为准。

## 快速使用

在支持 Skill 的 AI 助手（如 WorkBuddy）中说「按产品原型规范生成一个××页面/原型」即可触发。

## 约定摘要

- 默认技术栈 Vue 3，采用单文件 + CDN 依赖以便直接预览；用户指定其他技术栈或项目环境时按其要求执行。
- 使用 mock 数据，不接真实接口；页面中呈现为可操作的控件均可按预期操作。
- 按页面实际功能覆盖适用状态：空态、加载态、成功态、失败/异常态；需要展示的状态须可在原型中实际看到或触发。
- 交付说明以页内「标注层」形式提供，不单独输出文档。
