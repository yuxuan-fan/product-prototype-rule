# 产品原型规范（product-prototype-rule）

一套用于生成「可交互前端原型」的个人规范，供 AI 助手在用户明确要求按本规范生成/迭代原型时加载执行。

## 仓库结构

- `SKILL.md` — 规范正文（跨端通用）：核心原则、工作流程、布局基准、页面状态、组件规范、交互流转、设计 token、验收清单、交付说明。
- `references/b-end.md` — B 端默认基准：承载与预览、布局基准、组件默认、交付说明（标注层）、状态演示入口。
- `references/c-end.md` — C 端默认基准（手机 / 平板 / App / 小程序）：承载与预览、工程结构、布局基准、组件默认、交付说明、状态演示入口。
- `references/design-tokens.md` — 默认设计 token（基于 Arco Design 风格）：颜色、字号、间距、圆角阴影、现代视觉规范。用户提供了参考图时以参考图为准。

## 快速使用

在支持 Skill 的 AI 助手（如 WorkBuddy）中说「按产品原型规范生成一个××页面/原型」即可触发。

## 约定摘要

- 承载与端基准按目标端区分：B 端见 `references/b-end.md`（Vue 3 或 React，单文件 + CDN，直接浏览器预览）；C 端见 `references/c-end.md`（uni-app 工程，以 H5 端在浏览器预览与验收，可继续编译到小程序与 App）。用户指定其他技术栈或项目环境时按其要求执行。
- 使用 mock 数据，不接真实接口；页面中呈现为可操作的控件均可按预期操作。
- 按页面实际功能覆盖适用状态：空态、加载态、成功态、失败/异常态；需要展示的状态须可在原型中实际看到或触发。
- 交付说明与实现同源、迭代同步：B 端为页内「标注层」，C 端为工程内说明文档。
