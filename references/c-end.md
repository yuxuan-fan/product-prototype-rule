# C 端默认基准（手机 / 平板 / App / 小程序）

## 承载与预览

- 技术栈：uni-app 工程（Vue 语法）；视觉以 `references/design-tokens.md` 与参考图为准。
- 以 H5 端在本机浏览器预览与验收；运行 H5 端后用本地地址打开。同一套代码可继续编译到小程序与 App。

## 工程结构

- 页面放 `pages/`；路由、导航栏与 tabBar 在 `pages.json` 中配置；应用配置在 `manifest.json`。
- 多页面流转用 uni-app 的多页面：`pages.json` 配置页面，`uni.navigateTo` 等跳转，页面间跳转真实可操作。

## 布局基准

- **手机**：按 375pt 宽设计并兼容 414；使用 12 栅格、左右留白 16pt，以一屏一个主任务和卡片式布局为主。桌面浏览器打开时，默认以 375px 宽度居中呈现（容器限宽或设备壳），不随窗口拉伸。
- **平板**：以 1024×768 横屏优先，允许主从分栏（列表 + 详情）；竖屏按 768pt 单栏处理；不直接套用手机的 375pt 布局。
- **小程序**：内容区按 375pt；平台外壳由工程配置表达——导航栏（标题、背景、颜色）与可选的底部 tabBar（选中态用主色）在 `pages.json` 中配置，不做手绘外壳；无浏览器 chrome，注意底部安全区。
- 尺寸按 375pt 设计稿标注；实现时换算为 uni-app 的 rpx（750rpx = 屏宽，即设计稿 1px = 2rpx）。

## 组件默认

- 跟随参考图；无参考图时按页面任务采用常见移动端模式（如底部 Tab、底部操作栏或列表卡片），不要求每页都具备这些组件。

## 交付说明

- 不做页内标注：C 端以点按/长按交互为主，页内浮层批注会侵占交互与屏幕空间。
- 交付说明以工程内说明文档形式提供（如 `docs/交付说明.md`），与工程同源、迭代时同步更新；内容覆盖页面、字段、状态与交互。

验收要点：说明覆盖页面主要字段、状态与交互，与实现一致，迭代后同步更新。

## 状态演示入口

- 用 H5 地址参数进入（参数挂在目标页地址上，hash 路由下形如 `#/pages/xxx?state=empty`），页面不放工具入口，保持零侵入；编译到小程序时用等价的页面参数方式。
