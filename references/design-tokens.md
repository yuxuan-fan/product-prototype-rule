# 设计 token（基于 Arco Design 风格）

用户未提供参考图时使用以下默认值；用户提供了参考图时，以参考图为准。用户指定品牌色时，以用户为准。

## 颜色

| 语义 | 色值 | 用途 |
|------|------|------|
| 主色 | `#165DFF` | 主按钮、选中态、链接 |
| 主色浅底 | `#E8F3FF` | 选中项背景、hover 高亮 |
| 成功 | `#00B42A` | 通过、成功 |
| 警告 | `#FFB400` | 待处理、警示 |
| 错误 | `#F53F3F` | 驳回、删除 |
| 一级文字 | `#1D2129` | 标题、强调文字 |
| 二级文字 | `#4E5969` | 正文 |
| 三级文字 | `#86909C` | 说明、占位、辅助信息 |
| 禁用/弱文字 | `#C9CDD4` | 禁用态、更弱说明 |
| 边框 | `#E5E6EB` | 输入框、按钮、分割线 |
| 浅分隔 | `#F2F3F5` | 行分隔、区块分隔 |
| 页面底色 | `#F7F8FA` | 内容区背景 |
| 卡片 | `#FFFFFF` | 卡片、侧边栏 |

> 层次感来源：页面底 `#F7F8FA` 承托白色卡片，卡片之间用 `#F2F3F5` 细分隔；避免全白一片。

## 字号

| 层级 | 字号 | 用途 |
|------|------|------|
| 页面标题 | 20px / 600 | 页面大标题 |
| 卡片标题 | 16px / 600 | 卡片、区块标题 |
| 正文 | 14px / 400 | 表格、表单、列表 |
| 辅助文字 | 12px / 400 | 说明、时间戳 |

字体族：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`

## 间距（8pt 栅格）

基础单位 8px，常用档位：`4 / 8 / 12 / 16 / 24 / 32 / 48`。

- 卡片内边距：16px
- 卡片间距：16px
- 区块间距：24px
- 页面内容区边距：24~28px

## 圆角与阴影

- 圆角：卡片 12px，按钮/输入框 8px，弹窗 16px，胶囊 999px。
- 阴影（柔和）：卡片 `0 1px 2px rgba(0,0,0,.03)`，弹窗/浮层 `0 12px 32px rgba(0,0,0,.14)`。

## 现代视觉规范（默认基线）

- 页面存在卡片式内容时，默认用浅色页面底和白色卡片建立层次；若参考图或产品视觉另有要求，按其调整。
- 存在侧边导航时，默认使用白底浅色导航，选中项用「主色浅底 + 主色文字」。
- 存在数据表格时，默认用行分隔线代替满格框线，表头用浅灰底和次级文字色，并为行 hover 提供浅灰反馈。
- 展示状态标签时，默认用小圆点配彩色文字（成功 `#00B42A`、警告 `#FFB400`、错误 `#F53F3F`），避免厚重底色胶囊。
- 按钮、输入框默认添加约 `.15s` 的 hover 过渡和聚焦光圈；不支持 hover 的设备以合适的焦点或按压反馈为准。
- 展示金额等数字时，默认右对齐并使用等宽数字（`font-variant-numeric: tabular-nums`）。
- 每个主要操作区域或弹窗默认突出一个主按钮，其余动作使用次级样式；确有多个同级核心操作时按任务重要性处理。
