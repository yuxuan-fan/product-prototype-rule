# B 端默认基准（桌面 Web / SaaS 后台）

## 承载与预览

- 技术栈：Vue 3（或 React）。
- 单文件并通过 CDN 引入依赖，直接在本机浏览器打开预览。
- 多页面流转用 hash 路由切换页面视图，页面间跳转真实可操作。

## 布局基准

- 采用左侧导航 + 顶部栏 + 内容区。
- 使用 12 栅格，主内容占 8~10 栅格。
- 存在侧边栏时，默认在顶部设置 Logo 区：图标 + 产品名并排（图标用主色圆角方块占位，用户有品牌 Logo 时以用户提供为准）。

## 组件默认

- 数据表格默认不超过 8 列，超出时可用列显隐或详情抽屉。
- 抽屉：详情、编辑或筛选适合侧向展开时使用，宽度默认 400~600px。

## 交付说明（标注层）

交付说明以「标注层」形式内嵌在页面中，不单独输出文档。

- 页面提供一个「标注」开关，默认关闭；开关是工具按钮，不属于页面设计，需低调（小尺寸、弱视觉，不得抢主按钮的地位）。
- 仅保留字段级标注，不做区块级说明条或虚线框（会挤压布局、影响结构）。
- 字段级标注为「零侵入」：开启后字段外观不变，仅当鼠标悬停时显示说明（字段含义、点击行为、状态变化）。

验收要点：开关关闭时页面无任何标注痕迹、悬停无反应；开启后悬停字段能看到说明，且不被遮挡、不被裁剪、不溢出屏幕、不改变页面布局；说明内容清晰，不出现「一字一行」等排版错乱。

> 标注层替代旧式「页面右侧灰色字段明细栏」，与页面同源，迭代时同步更新。

## 状态演示入口

- 空态、加载态、失败/异常态等演示入口，以与「标注」开关同级的低调工具位承载，默认关闭，不属于页面设计。
